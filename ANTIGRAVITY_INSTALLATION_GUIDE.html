Antigravity App Installation and Login Guide (Windows)

📌 NOTE
Source: Avaya Confluence Wiki — Antigravity Installation and Login Guide

This guide walks Windows users through downloading, installing, and signing in to the Antigravity App using Google OAuth with the dedicated corporate Google Cloud Project ID: geminienterpriseprod.

1. Where to Download & How to Install (Windows)

System Requirements: Windows 10 or Windows 11 (64-bit)

🌐 Official Download Location

Download the Antigravity Windows App directly from: https://antigravity.google/

Option A: PowerShell Automated Setup (Recommended)

Open PowerShell and run the following command:

irm https://antigravity.google/cli/install.ps1 | iex

Option B: Command Prompt (CMD) Setup

If using standard Command Prompt (CMD), run:

curl -fsSL https://antigravity.google/cli/install.cmd -o install.cmd && install.cmd && del install.cmd

2. Step-by-Step Login Procedure

  1. Launch App: Open the Antigravity App or open a fresh terminal window.
  2. Start Sign-In: Initiate sign-in (or run agy in terminal).
  3. Select Login Method: When prompted, select Option 2: Use a Google Cloud Project.
  4. Authenticate: Sign in via browser using your corporate Avaya email (@avaya.com).
  5. Enter Project ID: After browser authentication completes, enter the project ID exactly as: 
    geminienterpriseprod

4. Validation Checklist

  • [x] Antigravity App installed and launches successfully on Windows.
  • [x] Google OAuth login completed in browser with your Avaya email.
  • [x] Project ID geminienterpriseprod entered successfully.
  • [x] Antigravity is active and ready for use.

5. Troubleshooting

Q1: Command not found or App shortcut missing after installation.

  • Fix: Close and reopen PowerShell / CMD or restart your workstation so Windows refreshes its system PATH environment variables.

Q2: Wrong account selected or authentication error.

  • Fix: Confirm that you selected Google OAuth and Option 2: Use a Google Cloud Project, and ensure you signed in with your @avaya.com email.

Q3: Project ID error.

  • Fix: Re-enter the project ID exactly as geminienterpriseprod.
