Antigravity App Installation and Login Guide

📌 NOTE
Source: Avaya Confluence Wiki — Antigravity Installation and Login Guide

This guide walks you through installing the Antigravity Desktop App and signing in using Google OAuth with the dedicated corporate Google Cloud Project ID: geminienterpriseprod.

1. Installing the Antigravity App

Download and run the installer for your operating system:

Operating System Installer Format Installation Steps
Windows .exe / .msi Installer Download the Windows installer (Antigravity Setup.exe) and double-click to launch the setup wizard. Follow on-screen prompts to complete installation.
macOS .dmg Package Download the macOS disk image (Antigravity.dmg), open it, and drag the Antigravity icon into your Applications folder.
Linux .deb / .rpm / .AppImage Download the appropriate package for your distribution and install via your system package manager or run the AppImage.

2. Step-by-Step Login Procedure

  1. Launch App: Open the Antigravity App from your Start Menu, Applications folder, or desktop shortcut.
  2. Start Sign-In: Click Sign In on the welcome screen.
  3. Select Login Method: When prompted, select Option 2: Use a Google Cloud Project.
  4. Authenticate: Sign in via browser using your corporate Avaya email (@avaya.com).
  5. Enter Project ID: After browser authentication completes, enter the project ID exactly as: 
    geminienterpriseprod

Step What to Enter / Select

4. Validation Checklist

  • [x] Antigravity App installed and launches successfully.
  • [x] Google OAuth login completed in browser with your Avaya email.
  • [x] Project ID geminienterpriseprod entered successfully.
  • [x] Antigravity App main interface is active.

5. Troubleshooting

Q1: Antigravity App fails to launch or closes immediately.

  • Fix: Verify system requirements and check if antivirus / corporate security software is blocking the application.

Q2: Wrong account selected or authentication error.

  • Fix: Confirm that you selected Google OAuth and Option 2: Use a Google Cloud Project, and ensure you signed in with your @avaya.com email.

Q3: Project ID error.

  • Fix: Re-enter the project ID exactly as geminienterpriseprod.
