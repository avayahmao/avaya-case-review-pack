Antigravity Desktop App Installation and Login Guide (Windows)

This guide walks Windows users through downloading, installing, and signing in to the Antigravity Desktop App using Google OAuth with the corporate Google Cloud Project ID: geminienterpriseprod.

1. Downloading & Installing the Antigravity App

System Requirements: Windows 10 or Windows 11 (64-bit)

📥 Official Download Location

Download the Windows Desktop App installer directly from the portal:

Go to https://antigravity.google/

Installation Steps:

  1. Visit https://antigravity.google/ and download Antigravity Setup.exe.
  2. Locate the downloaded Antigravity Setup.exe file in your Downloads folder.
  3. Double-click the file to start the installation wizard.
  4. Follow the prompts on screen. Shortcuts will be placed on your Desktop and Start Menu.

2. Step-by-Step Login Procedure

  1. Launch App: Open the Antigravity App from your Start Menu or Desktop shortcut.
  2. Start Sign-In: On the welcome screen, click Sign In.
  3. Select Login Method: Choose Option 2: Use a Google Cloud Project.
  4. Browser Authentication: A web browser window will open automatically. Sign in using your corporate Avaya email (@avaya.com).
  5. Enter Project ID: After browser authentication succeeds, enter the project ID exactly as: 
    geminienterpriseprod
  6. Complete Setup: Click Confirm to finish signing in and open the Antigravity main workspace.

5. Troubleshooting

Q1: App does not launch after installation.

  • Fix: Check Windows Security or corporate antivirus settings to ensure the application is permitted.

Q2: Wrong account selected or authentication error.

  • Fix: Make sure you select Option 2: Use a Google Cloud Project and sign in using your @avaya.com email address.

Q3: Invalid Project ID.

  • Fix: Re-enter the project ID exactly as geminienterpriseprod.
