Antigravity CLI Installation and Login Guide

📌 NOTE
Source: Avaya Confluence Wiki — Antigravity CLI Installation and Login Guide

This guide walks you through installing the Antigravity CLI (agy) and signing in using Google OAuth with the dedicated corporate Google Cloud Project ID: geminienterpriseprod.

1. Installation Commands

Select the command for your operating system and shell environment:

Operating System Terminal / Shell Installation Command
macOS Terminal curl -fsSL https://antigravity.google/cli/install.sh | bash
Linux Terminal curl -fsSL https://antigravity.google/cli/install.sh | bash
Windows PowerShell (Recommended) irm https://antigravity.google/cli/install.ps1 | iex
Windows Command Prompt (CMD) curl -fsSL https://antigravity.google/cli/install.cmd -o install.cmd && install.cmd && del install.cmd
💡 TIP
If you are unsure which terminal to use on Windows, PowerShell is the simplest and recommended option.

2. Step-by-Step Login Procedure

  1. Open Terminal: Close and reopen your terminal after installation completes.
  2. Start CLI: Run agy in your terminal.
  3. Select Login Method: When prompted, select Option 2: Use a Google Cloud Project.
  4. Authenticate: Sign in using your corporate Avaya email (@avaya.com).
  5. Enter Project ID: After browser authentication completes, enter the project ID exactly as: 
    geminienterpriseprod

  • [x] Antigravity CLI installation command completed successfully.

5. Troubleshooting

Q1: agy: command not found after installation.

  • Fix: Close and reopen your terminal window so the updated system PATH is loaded.

Q2: Wrong account selected or authentication error.

  • Fix: Confirm that you selected Google OAuth and Option 2: Use a Google Cloud Project, and ensure you signed in with your @avaya.com email.

Q3: Project ID error.

  • Fix: Re-enter the project ID exactly as geminienterpriseprod.
